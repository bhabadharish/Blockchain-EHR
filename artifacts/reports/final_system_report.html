A Two-Phase Architecture Synthesizing Clinical Data Confidentiality, Immutable Smart Contract Verification, and Deep Intrusion Telemetry Analysis.

1. Architectural Overview & Separation of Concerns

The fundamental scientific position of this research separates healthcare privacy from network intrusion detection into two distinct, correlated phases:

PHASE 1: Secure EHR Protection (Before/During Transmission)

Governs patient confidentiality, HIPAA Safe Harbor pseudonymization, authenticated symmetric encryption (AES-256-GCM), key management, and off-chain storage. Plaintext medical records are NEVER stored on the blockchain; only deterministic SHA-256 payload digests are anchored on-chain.

PHASE 2: Post-Encryption Breach Detection & Automated Response

Recognizes that encryption alone cannot stop environmental, transport, or API compromises. A high-throughput deep neural network (MI-CNN-BiLSTM-Attention) inspects surrounding network traffic telemetry (Edge-IIoTset) to detect MITM, DDoS, injection, and ransomware attacks, correlating intrusion predictions with on-chain cryptographic tamper proofs.

Core Layered Security Doctrine:
• Encryption protects confidentiality.
• Authenticated encryption (AEAD MAC tags) and hashing protect integrity.
• Blockchain provides tamper-evident notarization and non-repudiation.
• Access control smart contracts enforce role-based authorization.
• The AI IDS detects host and network anomalies in surrounding communications.
• The incident engine correlates these multi-layer signals to dispatch explainable SOC playbooks.

4. Blockchain Architecture: Local Ganache Node & Truffle Solidity Contracts

The primary blockchain implementation interfaces with a local Ethereum-compatible Ganache node running at http://127.0.0.1:8545 with network ID 1337.

EHRAccessControl.sol

Implements role-based access control (RBAC) with validity timestamps. Roles supported include ADMIN, DOCTOR, NURSE, RESEARCHER, AUDITOR, PATIENT, and SECURITY_ANALYST. Emits AccessGranted and AccessRevoked events upon state transitions.

EHRIntegrityRegistry.sol

Anchors cryptographic bytes32 payload hashes. Implements registerEHR(), verifyIntegrity(), and recordIncident(). Plaintext patient data is strictly excluded from storage and contract events.

Automated Truffle Tests: 8/8 test suites pass consistently (326 ms), validating deployment, registration, tamper detection, and incident emission.
